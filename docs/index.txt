OVERVIEW
--------
HADES is a voice-first AI personal assistant for Windows. It runs as a local
Python desktop app (pywebview GUI), uses Groq LLaMA 3.3 70B for conversation,
Piper TTS for offline speech output, and Google STT for voice input. The UI is
a sci-fi dark-themed animated orb. Optionally backed by Supabase for cloud
memory, multi-user auth, and semantic search over conversation history.

WHAT HAS BEEN BUILT (complete — v0.x)
--------------------------------------------------------------------------------

[CORE]
  - brain.py          Groq Llama 3.3 70B conversational AI. Two memory paths:
                        • Supabase (when user_id provided + Supabase configured):
                          two-tier — last 12 messages (recency) + top 5
                          semantically relevant past turns via pgvector cosine
                          search (retrieve_relevant), using all-MiniLM-L6-v2
                          embeddings. Messages persisted to conversation_memory
                          table after every reply.
                        • Local fallback: last 20 turns in
                          conversation_history.json. Thread-safe lock. Trimmed
                          and written to disk after every reply.
                      think() and clear_memory() both accept optional user_id.
  - voice.py          Piper TTS (offline neural, British male voice):
                        • Python API path (piper.PiperVoice + sounddevice);
                          CLI fallback (piper binary); print-only ultimate fallback
                        • _auto_download_piper(): on first run, downloads
                          en_GB-alan-medium.onnx + .onnx.json (~60 MB) from
                          HuggingFace if missing at ./voices/ — no manual download
                        • _speak_piper_api(): queries device native sample rate
                          (sd.query_devices), resamples Piper 22050 Hz → device
                          rate via np.interp, converts int16→float32 to eliminate
                          Windows audio-driver stuttering
                      Google STT via SpeechRecognition; configurable wake words
                      (WAKE_WORDS env var) with per-word fuzzy STT-mishear variant
                      sets; 2.5s debounce (WAKE_DEBOUNCE env var);
                      MIC_ERROR sentinel distinguishes mic failure from silence;
                      listen_for_wake_word_once() helper for sleep-mode checks;
                      no per-call ambient-noise calibration in listen() (dynamic
                      _energy_threshold handles it continuously)
  - main.py           Full voice loop (standby → wake → listen → think → speak),
                      true sleep mode (mic on but only wake word processed; orb
                      dims), 13-step intent router, text command handler with
                      sleep-word detection, _pending_state multi-turn state
                      machine. user_id threaded from auth callback through
                      route() to every handler. on_auth_complete callback
                      stores resolved user_id before voice loop starts.
  - config.py         .env loader for all API keys, Supabase credentials, and
                      settings flags (WAKE_WORDS, WAKE_DEBOUNCE, PIPER_MODEL,
                      FACE_AUTH_ENABLED, SUPABASE_URL, SUPABASE_ANON_KEY)
  - db.py             Centralised Supabase client (no other file imports supabase
                      directly). Lazy-init client and embedder. Exposes:
                        Auth: sign_in, sign_up, sign_in_magic_link,
                              restore_session, sign_out
                        Notes: add_note, get_notes, get_note_categories,
                               delete_last_note_db, delete_notes_db
                        Memory: save_message, load_recent, retrieve_relevant,
                                clear_memory_db
                        Util: is_available(), embed()
                      sign_in/sign_up use model_dump(mode='json') to ensure
                      JSON-safe session serialization (datetime → ISO strings).
  - gui.py            pywebview window, Python↔JS bridge, status/message helpers,
                      add_help_card(); full auth flow: on load, checks
                      ~/.jarvis/session.json for a valid token and restores the
                      session silently; if not found, shows login panel; HadesAPI
                      exposes login(), register(), magic_link(), skip_login();
                      session written to ~/.jarvis/session.json on success.
                      All JS error injection uses json.dumps() (safe for any char).

[FRONTEND]
  - frontend/index.html   Single-page dark sci-fi UI — animated orb with 4
                          rotating rings + tick marks, 5-state status system
                          (standby / sleeping / listening / thinking / speaking),
                          scrollable chat log, text input bar, help card
                          component (.help-card), login panel (email + password
                          form; magic link button with showMagicLinkSent()
                          confirmation; signup panel; skip button for local mode)

[COMMANDS]
  - commands.py       Volume (set/up/down/mute via pycaw + pyautogui), time &
                      date, battery, screenshot, clipboard read,
                      shutdown/restart/lock/cancel, notes (save with category +
                      read with filter + get_existing_categories; all db-aware
                      via _use_db(user_id) — falls back to notes.txt when no
                      Supabase), note deletion (delete_last_note, delete_notes
                      by category or all), timed reminders, web search, app
                      launcher, website opener, CPU/RAM/disk, HELP_HTML constant.
                      set_volume() uses getattr(speakers, '_dev', speakers) to
                      unwrap the pycaw AudioDevice wrapper before calling Activate
                      (compatible with both old and new pycaw versions).

[INTEGRATIONS]
  - weather.py        OpenWeatherMap — current weather by city
  - news.py           NewsAPI — top 5 headlines or topic-specific news
  - stocks.py         yfinance — live stock price; CoinGecko — crypto price
                      (BTC/ETH/SOL/DOGE/ADA/XRP)
  - spotify.py        Spotipy — play by query, pause/resume, skip, previous,
                      shuffle, current track; HTTP-status-aware error
                      summarization (401/403/404/429/503)
  - vision.py         Screen capture (PIL.ImageGrab) → Groq Llama 4 Scout
                      (meta-llama/llama-4-scout-17b-16e-instruct, multimodal);
                      HADES persona system prompt; image resized to 1280px,
                      base64 JPEG encoded; handles rate-limit errors

[AUTH]
  - face_auth.py      Optional face verification gate (OpenCV + face_recognition)
                      enabled via FACE_AUTH_ENABLED=true in .env. Register face:
                      python face_auth.py --register. Encodings stored in
                      face_encodings.pkl (gitignored).

[DISTRIBUTION]
  - install.bat       One-command Windows installer: creates venv, pip install,
                      downloads Piper CLI binary (no C++ Build Tools required),
                      downloads en_GB-alan-medium voice model, copies .env.example
                      → .env. All steps idempotent (skips if already present).
  - setup.py          pip install -e . support; entry point `hades = main:main`
  - supabase_schema.sql  SQL to run in Supabase SQL editor: creates notes and
                      conversation_memory tables (role column has CHECK constraint),
                      RLS policies, match_memory() pgvector cosine-search function,
                      IVFFlat index on embedding column for fast similarity search.
  - run_once_migrate_notes.py  Imports existing notes.txt into Supabase (one-time
                      migration); preserves timestamps + categories; renames
                      notes.txt → notes.txt.bak on success.
  - smoke_test.py     Pre-flight API key check: Groq / OpenWeatherMap / NewsAPI /
                      Spotify / Supabase (auth endpoint + schema table existence);
                      PASS/FAIL/SKIP per key; exits 1 on any failure.

[TESTS]
  - tests/test_route.py   24 unit tests for main.py:route() — all routing
                          branches covered, all dependencies mocked; runs with
                          `pytest tests/` (no API keys, mic, or Piper needed)

WHAT STILL NEEDS TO BE BUILT (v1.0+ roadmap)
--------------------------------------------------------------------------------

[v1.0 — NEXT UP (in active planning — Phases 14-16)]

  PHASE 14 — Neural Wake Word (openWakeWord)
    Replace the current fuzzy-STT polling loop with a lightweight neural
    model that runs continuously on the mic stream. openWakeWord detects the
    wake word acoustically without transcribing every utterance — far fewer
    false triggers, lower CPU, and works even when ambient noise confuses STT.
    Files: voice.py (wait_for_wake_word), requirements.txt, .env.example
    Prerequisite for: Continuous Conversation (Phase 15)

  PHASE 15 — Continuous Conversation (hold-open window)
    After HADES replies, keep the mic active for a configurable follow-up
    window (default ~15s) before returning to standby. The user can ask
    "what about next week?" without re-saying the wake word. A silence timeout
    or sleep-word exits the window and returns to standby.
    Files: main.py (hades_loop inner loop), config.py (FOLLOWUP_TIMEOUT env)
    Depends on: Phase 14 (reliable wake detection before relaxing the loop)

  PHASE 16 — Action Confirmation Gate
    Destructive or irreversible actions (shutdown, delete all notes, restart,
    send message) require a spoken or clicked confirmation before execution.
    HADES asks "Are you sure, Sir?" — "yes/confirm" proceeds; anything else
    cancels. Prerequisite for safe calendar (write) and email (send) features.
    Files: main.py (confirmation state machine), commands.py (gate decorators)

[v1.0 — remaining items]
  - Barge-in / interruptible speech: talk over HADES to stop or redirect
  - Action log: reviewable history of what HADES did and when
  - Untrusted-input handling: screen/web/email text treated as data only

[v1.5 — "Life manager"]
  - Google Calendar integration (read agenda, create/move events)
  - Gmail assistant (triage, summarize, draft; sends only after confirmation)
  - Morning/evening briefings (proactive digest: weather, calendar, headlines)
  - File search ("find my resume", "open the budget spreadsheet")
  - Routines/macros ("Good morning" → lights + brief + playlist)
  - Timers, alarms, stopwatch by voice

[v2.0 — "Anticipatory & extensible"]
  - Proactive nudges (context-aware, rationed suggestions)
  - Web research agent (search, open, summarize pages; multi-source answers)
  - Document/PDF Q&A (local RAG)
  - Skill/plugin system (drop-in user skills via skill.json + handler.py)
  - Smart-home bridge (Home Assistant: lights, thermostat, scenes)
  - Mobile companion (trigger HADES from phone on same network)

[v2.5 — "Multi-modal & personal"]
  - Webcam vision (object/scene awareness, OCR, document capture)
  - Speaker identification (recognize who is speaking, load their profile)
  - Adjustable persona (tone/verbosity/wit dial, multiple TTS voices)
  - Translation (speak/translate between languages on the fly)
  - Developer mode (explain/run snippets, git status, project Q&A)

KNOWN ISSUES / BUGS
--------------------------------------------------------------------------------

  - None currently documented. File bugs here as discovered.

  FIXED (Session 009)
  - Volume commands crash with AttributeError 'AudioDevice' object has no
    attribute 'Activate': newer pycaw wraps the COM device in an AudioDevice
    object; set_volume() now unwraps it with getattr(_dev). (commands.py)
  - Session saved to ~/.jarvis/session.json crashes with TypeError on datetime
    fields: sign_in/sign_up now use model_dump(mode='json'). (db.py)
  - JS error injection via f-string could silently produce broken JS for
    messages with apostrophes, backticks, or newlines: switched to json.dumps().
    (gui.py)
  - Magic link button missing from login panel UI despite backend support;
    magic_link() method also missing from HadesAPI. Both now added. (gui.py,
    frontend/index.html)
  - IVFFlat index and role CHECK constraint missing from supabase_schema.sql
    (were specified in doc 07 but not in the SQL file). Both added. (supabase_schema.sql)
  - smoke_test.py Supabase check only tested auth endpoint reachability, not
    whether the schema had been run. Now also queries both tables. (smoke_test.py)

  FIXED (Session 007)
  - Audio stuttering during Piper TTS playback: sample-rate mismatch (Piper
    22050 Hz vs Windows device 44100/48000 Hz). Fixed via device-rate query +
    np.interp resampling + int16→float32 conversion in _speak_piper_api().
  - ~1 second delay between wake word detection and "Yes, Sir?": caused by an
    unconditional time.sleep(0.3). Removed; synthesis begins immediately.

  FIXED (Session 006)
  - Sleep via text input not updating the UI orb state. Fixed with _text_state
    closure dict and early return in handle_text_command().
  - Vision responses sounding generic (not HADES). Fixed with HADES persona
    system prompt in vision.py Groq API call.
